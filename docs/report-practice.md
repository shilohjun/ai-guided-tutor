# 学习报告与定向练习

报告保留学习小结、知识与方法、卡点与改进。重做、结束位于滚动区域外的顶部操作栏。
取消独立第五页；旧页码5指向报告。跳过报告通过解题页“继续练习”复用抽屉。

## 匹配规则

- 知识/方法：使用题库完整知识与方法ID数组；题目排除当前题，难度不超过当前题，按难度排序。
- 卡点：必须具有明确错误证据，以及 `report-practice.js` 中核读过题干、设问、解析的具体映射。
- 表达困惑、数值错误但错因不明、无法定位的卡点，均不使用宽泛知识标签补位。
- 暂无已核验且难度合适的候选时不显示卡点练习按钮；不表示整个题库不存在相关题。
- 客户端排除本轮已经练习的题，每次最多展示3道，不自动扩大针对性推荐范围。

## 当前核读覆盖与限制

仅对内置电磁感应题 `phy-emi-01/04` 中有错误证据的 `circuit` 卡点建立专项映射：
`GZ-2026-10`（贵州第10题）的电流关系要求计入接入回路的导体棒电阻。
湖南第5题的电池组内阻不能替代“导体棒电阻遗漏”的专项映射。
贵州题难度为3，故难度为2的内置第1题暂不推荐该题，难度为3的内置第4题可推荐。
该映射为源码核读，尚不等同于教师复核或学生试验验证。扩展时需补充明确训练目标、适用题型、题号与理由。
题库题尚无专用作答判断量规，不能仅凭其知识标签生成卡点专项推荐。
题目难度仅为题库等级，不代表已测量学生能力。

## 会话与数据

从报告开练/重做会保留当前报告上下文，可通过“返回原报告”恢复原会话及滚动位置。
记录依赖现有服务端会话及浏览器内存；本次没有添加持久化、长期掌握判断或模型调用。
报告接口只返回题号、难度、训练目标、推荐理由等公开元数据，不输出答案与解析。

## 完整题目预览

点击推荐题仅打开原生 dialog，按需读取公开的 `/qbank/q/{id}.json`，显示完整题干、原图公式、示意图和选项。
预览不会创建会话或替换当前报告。关闭按钮、Esc、遮罩外侧均可退出，并回到原推荐列表。
正文独立滚动，确认按钮固定在弹窗底部。确认“开始练习”才请求题目接口并开启新会话，保留返回原报告能力。
预览失败时保留当前会话并禁用开练；关闭后的迟到响应不会覆盖后续预览。开始请求期间关闭预览会取消后续页面切换。
仅使用公开题目数据，不读取或展示答案、解析；渲染只允许题目文字排版标签和内嵌图片，不保留脚本或事件属性。
