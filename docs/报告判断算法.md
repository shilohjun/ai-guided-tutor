# 学习报告：证据判定规则（evidence-v1）

本次修改只涉及报告。学习小结保持原有卡片、指标及三档布局；标题改为“学习小结”。“错题摘要”改为“卡点与改进”。不修改辅导提示词、对话模式、知识与方法卡片或练习入口。

## 数据链路

`appendTurn → record.hintLog → assessLearning → report.assessment → renderReport`

以服务端保存的学生原话为依据，结合题目专属核验规则、当前步骤与此前实际给出的提示。没有新增模型调用，也不依靠 AI 回复中的知识点标签推断学生掌握情况。前端不再把未讨论的知识点补为“掌握”。

## 知识点状态

- **掌握**：本题规则核验为正确；没有此前具体提示或错误；同时给出与该知识点相关的解释依据。只代表本题表现。
- **待巩固**：出现一次明确错误、提示后答对、纠正后答对，或正确但解释依据不足。
- **薄弱**：针对同一知识点获得有效的 L2/L3 提示后，至少在两个不同轮次继续出现可核验错误，且最新有效作答未纠正。
- **暂无法判断**：没有对应证据，只有“不会/不知道/懂了”、问题、假设、引用他人话语、冲突表达或无法核验的改写。接口保留 unknown，不强行放进三档；页面显示“暂无充分证据”。

具体提示指未被抑制、未被守卫判为失败、非确认/拒绝/兜底的 L2/L3 提示，并关联同一路径的同一步骤。复述 AI 原话不算独立证据。后续正确作答只修正同一知识点，不自动清除其他卡点。

## 正确率

当前题目首次独立作答正确率 = 首次独立答对的可核验小问数 / 有可核验首次独立作答的小问数。

要求明确标出待求量（如 E）并提交带单位的数值。数值和单位按现有参考答案解析器核验；未提交、仅提问、裸数字、歧义表达及尚无法核验的表达不进分母。首次错误后改正，保留首次错误记录；重复提交不增加计数。

没有经过审核的“提示对应哪一小问”映射时，已接受任何具体提示后的首次答案保守排除，不宣称独立完成。零有效样本显示“—”，鼠标悬停可看计数口径。该百分比不是综合能力分数，也不是所有对话步骤的正确率。

## 卡点与改进

最多三条，未解决优先；每条包含标题、状态、具体困难、下一步动作及可展开的学生原话。错误数值可以提示核算，但不据此猜测概念错因。已经纠正的标“本题已纠正”，不继续保持薄弱标签。“不知道”只提示需要补充步骤，不判成概念错误。

## 当前覆盖与扩展

题库 phy-emi-01～05 配有明确的知识/方法核验规则；数值核验复用 expectedAnswers 的待求量映射。任意导入题、证明题、等价公式、复杂单位换算及未配置的知识点不保证识别，证据不足时保持未知。不能把规则命中称为人工教研审核或完整语义理解。

扩展时先为题型补充“正确表达、错误表达、解释依据、步骤映射、改进行动”，再补真实学生措辞的测试。若后续增加模型提取证据，必须验证引用确实来自学生原话，并继续由确定性规则计算状态，不允许模型自行生成掌握百分比。
