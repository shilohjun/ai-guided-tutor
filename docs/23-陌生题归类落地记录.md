# 陌生题归类：让新题落到既有知识树

> 目标：学生粘贴/拍照进来的题不在题库里，但它的**知识位置**应该在。
> 归对了，报告页才有位置卡、才有"巩固练习"、推荐才不是字面匹配。

## 一、结论先说

| 口径 | 数字 |
| --- | --- |
| 词法检索，正确叶节点进 top-5（真·留出法，全量 835 题） | 74.3% |
| 词法检索，进 top-3 | 65.0% |
| 词法检索，top-1 | 36.5% |
| 模型在 5 个候选里选（实跑 40 题，剔除自身） | **61.1%**（n=36 表态） |
| 同一批题上词法 top-1 | 50.0% |
| 模型没把握时的弃权率 | 10%（4/40） |

**为什么不是 95.7%**：早先那版测法有两处泄漏 —— ① 建节点画像时没把被查的题自己剔掉，
② top-5 统计把"没命中"（下标 -1）也算成了命中。两处修掉后就是上表。这条要记着：
**留一法和"命中判定"是最容易自欺的两个地方。**

**为什么 61% 也算能用**：它不是"最终答案"，是"给报告页定位 + 给练习推荐排序"。
错一档的代价是卡片位置偏一章；不归类的代价是整页空白。而且模型还会弃权。

## 二、做法

```
题干 ──→ 词法检索（BM25 骨架，无 idf） ──→ 5 个知识叶 + 5 个方法节点候选
                                              │
                        ┌─────────────────────┴─────────────────────┐
                        │ 有模型：候选清单进提示词，模型在闭集里选      │
                        │ 无模型：直接取检索 top1（置信度够才取）      │
                        │ 都不像：留空（taxonomySource = 'none'）     │
                        └───────────────────────────────────────────┘
```

- **一题一块，不做分块**：一道题 259 字，本身就是一个语义单元，切开只会把条件切散。
- **不上向量库**：94 个叶节点的"画像"就是该节点下所有题的结构化文字，BM25 打分毫秒级；
  见 `docs/24-为什么不装向量库.md`。
- **闭集**：模型只能从候选里挑。候选外的一律丢弃并告警 —— 允许它"发明知识点"，
  等于让报告页挂上一个不存在的位置。
- **可弃权**：`MIN_LEAF_SCORE = 8`。标定方式见下。

## 三、阈值怎么定的

`.tmp-rag/calib.mjs`：把与物理无关的句子喂进分类器，top1 只有 0.2–2.1 分；
真题 top1 的 p10 是 13.7、最低 7.7。阈值取 8，落在两者之间的空档里。
所以"随便一句话"不会被硬归到某个知识点上。

## 四、接到哪儿了

| 位置 | 改动 | 效果 |
| --- | --- | --- |
| `src/core/taxonomy.js`（新） | 建立索引 + 分类 + 卡片 | 94 叶 / 38 方法；加载 180ms、首查 181ms、热查 0ms |
| `src/core/intake.js` | 读题时懒加载候选，`pickTaxonomy` 落字段 | Problem 多出 `leafId` / `methodIds` / `taxonomySource` |
| `src/core/llm.js` | 提示词追加候选清单 + schema 字段 | 模型从"自由发挥"变成"闭集选择" |
| `src/core/report-review.js` | 陌生题返回**位置卡** | 报告页不再空白；明确写"只定位、不含讲解" |
| `src/core/report-practice.js` | 陌生题用路径现场拼关键点 | "巩固练习"能按叶子从题库捞题 |
| `src/core/intake.js` | 读题总预算 45s | 模型不回包时降级骨架，不把请求挂死 |

**为什么位置卡不写讲解**：题库里只有电磁感应那 14 张是教研手写的，其余 80 个叶节点没有文案。
硬让模型现编一段"本节讲解"，等于在复盘页编教材 —— 比留空更坏。

## 五、踩过的坑

1. **成员 id 没赋对**：`members.push(d.i)` 里 `d` 是 `{q,g,qg,len}`，`d.i` 恒为 `undefined`
   → 留一法的"剔除自己"永远不生效 → 数字虚高。
2. **未命中算命中**：`if (idx < 5) h5 += 1`，`idx = -1` 也进档。
3. **画像与查询不同源**：画像含该题全文（自匹配），查询只含题干 —— 用同一份数据做画像和评测，
   测出来的永远是"自己认识自己"。
4. **一次 39 分钟不回的模型调用**：真模型自带 45s AbortController，但出现过连接建立后
   长时间不返回的情况。现在读题外层还有一道 45s 总预算，到点降级。

## 六、还没做

- **把相似真题的拆解结构注入提示词**（真正的 RAG 运行时动作）：现在注入的是"候选节点"，
  还没注入"同类题通常怎么拆"。做的时候要量一次：拆解结构有没有让定位更准，而不是只让提示更长。
- **embedding 版对照**：词法 top-1 36.5% 是明确要打败的基线。embedding 上不了 45% 就不值得引入模型依赖。
- **方法节点归类的准确率没单独测**：现在只测了叶节点，方法 top-1 更差（约 41%），
  所以线上允许空。
