# 离线话术「去 AI 味」前后对比

> 本文记录本轮对**学生可见话术**的修改：每一处改动都给出**修改前**与**修改后**两版代码，
> 并说明它治的是哪一种毛病。
>
> 阅读顺序：先看 §1 弄清"改的是哪条链路"，再看 §3 逐项代码对比，最后看 §4 的真实文案效果与 §5 验证结果。

---

## 1. 背景：为什么改这里，而不是改系统提示词

产品的提示词**不在** `public/`，而在 `src/core/llm.js`。前端 `public/` 只是壳子，
所有文本都由 `src/` 里的引擎产出：

```
public/index.html + app.js      ← 前端壳（不含任何提示词）
        │  /api/chat …
        ▼
src/server/router.js            ← 业务编排
        ▼
src/core/engine.js → llm.js     ← 三条系统提示词在这里
        ▲
        ├─ 配了 LLM_API_KEY ⇒ 真模型，吃系统提示词
        └─ 没配 Key        ⇒ 离线规则桩，**不吃**系统提示词（是写死的模板）
```

本机的默认链路是**离线规则桩**（仓库里没有 `.env`）。也就是说：

- 只改三条系统提示词，`http://127.0.0.1:5173` 上**看不到任何变化**；
- 想让本地页面"变好看、少点 AI 味"，必须改**产出学生可见文本的那几处模板**。

本轮改动**只动文本、不动逻辑**：层级决策、守卫判定、定位结果一律不变，
因此安全指标与能力指标都应保持不变（§5 有实测）。

改变的文件（全部在 `src/core/` 下）：

| 文件 | 改了什么 |
|---|---|
| `engine.js` | 拒绝话术阶梯（含一处**写死「匀速」的真 bug**） |
| `llm.js` | 离线桩 L2 方向变体（去占位符病句）、L3 示范（去写死「物理/回路」） |
| `guard.js` | L2 安全兜底模板（去教研味前缀） |
| `locate.js` | 复述段（同一件事说两遍）、反问句（自相矛盾的承诺） |
| `prompt.js` | 复述去重规则（把"碰巧生效"改成"确定生效"） |
| `route.js` | 策略文本写死「物理方向」 |
| `report.js` | 报告标题空学科、drill 写死「物理条件」 |

## 2. 改动的三类毛病

1. **写死学科/题目** —— 产品支持数学、化学，但话术里塞着「物理」「回路」「受力」，
   数学证明题会收到一句风马牛不相及的提示。这类**必须改**，是事实错误。
2. **占位符/自指病句** —— 模板变量取不到值时会漏出「题目里的另一个条件」，
   甚至写出"忽略了**它**对**题目里的另一个条件**的影响"这种自指句。
3. **多余的话与元评论** —— 同一件事说两遍（复述里"你打算用欧姆定律"+"你的推理走到了「我用欧姆定律…」"）、
   教研侧标签（"方向提示："）、过度承诺与说教（"我可以保证…""这比我报个数字对你考试有用得多"）。

### 3.6 `src/core/prompt.js` — 复述去重：把"碰巧生效"改成"确定生效"

**这是本轮唯一的逻辑级改动，也是被 §3.5 逼出来的。**

原先"复述该不该丢"靠的是**字符重合率 > 0.6** 的启发式（`isRedundant`）。
在 L0 上，反问句和 L0 提示恰好都在问"题目给了什么、要求什么"，字符重合率超标 ⇒ 复述被丢掉。
但 §3.5 把反问句结尾那句承诺删掉后，重合率掉到阈值以下 ⇒ **复述又没有丢**，
学生就会连着看到两遍同一个问题（实测回归，见 §4 末）。

与其调阈值，不如按层级**显式判定**：L0 的提示本身就是那个澄清问题，任何复述都是第二次发问。

```diff
 function safeRestatement(restatement, hint) {
   if (!restatement) return null;
   let r = restatement.trim();
 
+  /**
+   * L0 的提示本身就是"把题目给了什么、要求什么说一遍"这个澄清问题。
+   * 此时任何复述都是同一件事的第二次发问 —— 学生看到的是连着问两遍。
+   * 这里用层级显式判定，而不是依赖下面的字符重合率启发式：
+   * 启发式只能碰巧命中，一旦提示词换了措辞（例如去掉一句结尾承诺）就会漏判。
+   */
+  if (hint?.level === 0) return null;
+
   // 复述与提示高度重合 ⇒ 丢掉复述，避免"问了两次同样的问题"
   if (isRedundant(r, [hint.text])) return null;
```

**② 不再漏出占位符、不再自指（场景 `sc-02` / `sc-05`，L2）**

```text
【改前】换个角度：你把「含内阻电路」也一起考虑进来了吗？这一步卡住，往往是因为只盯着闭合电路欧姆定律，忽略了它对含内阻电路的影响。
```

