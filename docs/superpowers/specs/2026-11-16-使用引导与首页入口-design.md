# 使用引导与首页入口 —— 设计

日期：2026-11-16
状态：待审
关联：`docs/17-陪学老师-接入说明.md`、`docs/superpowers/specs/2026-11-02-设置面板-主题与字号-design.md`

## 一句话

首页底部那条「好题精练」按钮取消，换成一次性的**三步使用引导**：第一步让学生当场在「发自己的题」和「从精选题库挑（推荐）」之间选一条；第二步交代怎么定讲法；第三步在解题页浮一句「我只给提示，不给答案」。三步共用一个进度值（`localStorage['bsj-guide']`，空 → `1` → `2` → `done`），走完或跳过后不再自动出现，设置面板里可以重看。同时把题库的默认视角从「思路」改成「知识点」，第 2 页那条与模式卡等大的「陪学老师」长条收成一行头像。

## 为什么做

三件彼此咬合的事：

1. **首页没有教过任何人怎么开始。** 现在 `#goodBar` 是首页唯一看得见的题库入口（`public/index.html:1681-1685`），点它才滚到下面的题库地图。它是一条**按钮**，不是一句**话** —— 学生看到"好题精练"四个字，不知道那是"我没题的时候可以从这儿挑"，也不知道"我有题的话上面那个框就行"。两条路从来没有人说清过。
2. **题库一进去是「思路」轴，不是「知识点」轴。** `public/qbank/map.html:749` 写死 `view: QP.get('view') === 'kg' ? 'kg' : 'th'`，默认落在思路；宿主顶栏 `#bankSeg` 的初始选中态也是思路（`public/index.html:1570-1573`）。而「按知识点选题」是这个产品对外讲的第一句话。
3. **第 2 页是三张一模一样的长条。** 自主训练、AI 伴学（禁用）、陪学老师，都是 748px 宽、48px 图标、24px 圆角、`padding:16px`（`public/index.html:891-921`、`:955`）。老师只是"同一道题的不同讲法"，分量却和"选哪种做题方式"一样重；点开还要再开一层浮层（`:1741`、`:2612-2622`）。

## 目标

- **G1** 首页不再有常驻的「好题精练」大按钮；题库入口由引导和版面暗示承担。
- **G2** 第一次进来的人，在首屏内就能看懂两条路，并且知道我们推荐哪一条。
- **G3** 引导走完/跳过后不再自动出现；设置面板里能重看一遍。
- **G4** 题库默认落在「知识点」轴，且顶栏的分段控件与 iframe 内部状态永远一致。
- **G5** 第 2 页从"三连条"变成"两张模式卡 + 一行讲法的人"，老师仍然可选、仍然记得住。
- **G6** `npm test`（含 `scripts/audit-ui-style.js`）全绿；间距/圆角/字号仍走既有白名单。

## 非目标

- 不重排首屏版面（hero、输入框、垂直居中都保持现状）。
- 不改题库数据、不改引擎、不改提示策略、不改报告。
- 不做移动端专用的第二套引导。
- 不引入第三方引导/漫游库（本仓库零依赖，`package.json` 里 `dependencies: {}`）。
- 不动 `public/qbank/map.html` 自己的首屏（它只在**非嵌入**模式出现，`map.html:1766` 里 `home.style.display='none'`）。
- 不动旧壳：`shell.*`、`youth.css`、`classic.html`。

## 反目标（做成了也算失败）

- 引导盖住输入框，或者用全屏遮罩让学生第一反应去找叉。
- 引导第二次、第三次还在弹。
- 两张引导卡同屏（切页时上一步没卸掉）。
- 引导卡压住设置面板 —— 那里面才有"重看一遍"。
- 删了按钮之后，老用户第二次进来**完全找不到**题库。
- 顶栏显示「知识点」而地图里还是「思路」。
- 老师那一行点不动，或者换完人重启又变回派蒙。
- 引导卡在 667px 高的手机上压住输入框的发送键。

## 约束（来自代码的事实）

- **单文件**：`public/index.html` 一个文件装 markup + 内联 `<style>` + 内联 `<script>`，由 `server/server.js` 直接静态发出，没有构建步骤。
- **审计脚本的整数白名单**：间距只收 2/4/6/8/12/16/24/32，圆角只收 0/2/4/8/10/12/16/24/999（或 `--r-*` token），字号只能来自 `--fs-*`，字重 400/500/600/700，颜色饱和度 ≤ 70%（`scripts/audit-ui-style.js:36-38`、`:117-138`）。嵌套圆角外 = 内 + 间距是手工登记的（`:142-154`）。
- **一屏最多四种字号**：审计按选择器前缀把 `.p1`/`.p2` 分组，`set.size > 4` 就报错（`:210-226`）。第 1 页现在只有 `--fs-meta` / `--fs-body` / `--fs-lead` 三种，新卡片最多再加一种。
- **DOM 契约测试**：`test/ui.test.js:70-78` 会从内联脚本里抓每个 `$('#id')`，回到 markup 核对。删掉一个 id 必须同时删掉所有引用，否则红。
- **README 里的用例数被测试钉住**：`test/docs.test.js:76-107` 从源码数出实际注册数，再核对文档里"当前规模"的数字（README:17、:308 等处）。
- **pilot 埋点在读 `#goodBar`**：`public/pilot.html:1048-1053` 用 `target.closest('#goodBar')` 记 `intake: 'qbank'`，并明确写着"这三个 id 是成品页的公开结构，只读不写"。
- **嵌入模式**：宿主用 `map.html?embedded=1&theme=…` 装 iframe（`public/index.html:3701`），**没有带 view 参数** —— 所以地图内部默认值就是最终默认值。
- **`?p=N` 深链**：`maybeReviewJump()`（`:3927-3940`）会真实跑一遍读题再落页，`?guide=` 需要和它共存。
- **已有 localStorage 命名**：`bsj-theme`、`bsj-ux`、`bsj-mentor`，格式是 `bsj-<域>`。

## 方案（三条路，选了第三条）

用户先否决了"重排首屏"，又明确要"一个引导"，所以这条选择已经由用户定了。这里把三条路记下来，是为了留下"为什么不选另外两条"。

| | 做法 | 好处 | 代价 / 为什么不选 |
|---|---|---|---|
| A | 首屏浮层讲解：遮罩 + 两张卡，点「知道了」淡出 | 讲得最清，一次说完 | 遮罩在手机上挡输入框；学生第一反应是找叉；讲完还是得自己滑。**用户否决了这条路** |
| B | 首屏重排成两条路（版面即引导，不弹任何东西） | 没有关掉就忘，推荐靠视觉权重 | **用户明确说"不是首屏重排"** |
| **C（选）** | **一次性的三步引导**（卡片 + 目标高亮环，无遮罩），走完即退场，可重看 | 讲得清、可跳过、不挡操作；三步分别落在真正发生事情的那一屏；和已有 `PAGES` 流程同一套心智 | 要维护一个小状态机；引导只在第一次出现，老用户要靠版面暗示 + 滚动 |

C 的风险是"走到一半没做完"。处理方式：**任何一步都能整轮退出**（跳过、Esc、点卡片上的叉），不做"必须走完"的枷锁；走完一步就记一步的进度，下次从停下的地方接着来。

## 引导的形态

**不遮罩。** 一层满屏半透明会把"教他做一件事"变成"让他读一段话"，而且和 `.rel-drawer`、`.mentor-mask`、`#setMask` 三套已经存在的浮层抢层级。

组成两件东西：

1. **引导卡** `#guide`：`position:fixed`，水平居中，桌面 `bottom:24px`、手机 `bottom:16px`，**`z-index:39`**。宽 `min(560px, calc(100vw - 32px))`，`padding:16px`，圆角 `var(--r-card)`，`1px solid var(--line)`，`var(--shadow-2)`。
2. **目标高亮环** `#guideRing`：一个 `position:fixed` 的绝对定位盒子，照着目标元素的 `getBoundingClientRect()` 摆位，`box-shadow:0 0 0 3px var(--brand)`、`border-radius:var(--r-card)`、`pointer-events:none`、`aria-hidden="true"`。窗口 `resize` / 页面滚动时重新定位。不发光、不闪烁，只描一圈。

**为什么是 39**（这一条被审阅挑出来过，原文写的 55 是错的）：现有层级是 `.page` 2 / `.topbar` 30 / 设置遮罩·面板 40·41 / 符号面板 45 / 同类题遮罩·抽屉 55·56 / 老师浮层 60·61 / 查看器 70 / 题库遮罩 80（`:212`、`:345`、`:367`、`:621`、`:682-687`、`:846`、`:958-960`、`:1444`、`:1457`）。55 已经被同类题遮罩占用，而且会把卡片压在设置面板（41）**上面** —— 手机上的设置面板是贴底整宽抽屉（`@media (max-width:760px)`），正好和卡片同一个位置。取 39 之后：卡片在页面内容与顶栏之上、在**所有**用户主动打开的浮层之下，不需要写"打开浮层就收起卡片"这种会抖的逻辑。

**挂载位置**：卡片、高亮环、提示条都挂在 `body` 上（像 `#symPanel`、`#mentorDlg` 一样），**不能**放进第 1 页那个 `<section class="page">` —— 非激活页是 `display:none`（`:367-369`），放到里面就会在切页时凭空消失。

**不动焦点**：卡片出现时不抢焦点、不自动 `focus()`，避免打断已经开始的输入。Esc 关闭 = 跳过整轮。

**首屏让位**：第 1 步打开时给 `.p1-screen` 加 `padding-bottom:180px`（`body[data-guide="1"]` 触发），让 flex 居中把 hero 与输入框整体上推，卡片不压输入框。这条只在引导打开时生效，关掉即还原。

**reduced-motion**：入场动画关掉，卡片直接出现；箭头/圆点动画不跑。

## 三步的内容与动作

### 第 1 步 · 从哪出道题（首页）

卡片内容：

```
先定从哪出道题                                   ✕
─────────────────────────────────────────────────
[✎] 我有题，直接发给你
     拍照或粘贴，按你的题讲
[✦] 从精选题库挑一道        [推荐]
     835 道高考真题，默认按知识点挑
                                跳过引导
```

- 高亮环罩住 `#composer1`。
- 点**第一条** → `#input1.focus()` → **进度记到 1，本轮继续**（不是结束）。不强制他立刻发。
- 点**第二条** → 调 `window.__openBank()`（已有的那个，`:3731`）→ **进度记到 1，本轮继续**。顺手把顶栏 `#bankSeg` 与地图都切到知识点。
- 点 `跳过引导` / `✕` / Esc → 整轮结束（进度记 `done`）。
- 注意：点完两个选项之一并不写 `done`。**选了"从哪出道题"不等于讲了"怎么讲"**，第 2 步该来还会来。

### 第 2 步 · 再定怎么讲（第 2 页）

`setPage(2)` 之后 300ms 出现（由 `syncGuide()` 决定，见「触发时机」）。内容：

```
再定怎么讲                                       ✕
AI 伴学还在做，先选自主训练：先自己写，
卡住再要提示。想换个人讲，点下面那四个头像。
                                          [接着走]
```

- 高亮环罩住 `#modeList` 里第一张卡。
- 只有一个按钮「接着走」→ **进度记到 2**。它不结束整轮，只是不再重复第 2 步；第 3 步的提示条还欠着。
- 它解释的是现在最容易让人以为"坏了"的地方：第二张卡为什么是灰的。

### 第 3 步 · 卡住了就说（第 3 页，被动）

不用卡片，用一条**提示条** `#guideToast`：输入框上方一条，白底 + 品牌色左描边：

```
卡在哪就说哪，我只给提示，不给答案。            ✕
```

- 6 秒后自动淡出；**右侧有一个看得见的 ✕**，点它立刻收掉（整条点哪都能关，但"能点"这件事看不出来，所以补一个显式出口）。
- 不拦操作、不抢焦点。
- 它淡出/被点掉的那一刻，**进度记 `done`** —— 整轮到此为止。学生如果直接关页面、没看到它消失，进度就停在 `2`，下次进解题页会再浮一次；那是一条 6 秒的提示条，不是卡片，重复一次可以接受。
- 第 4 页（报告）不做引导 —— 那一页本身是结果，不需要教。

### 触发时机

全部由**一个** `syncGuide()` 决定，它被 `setPage()` 末尾、`DOMContentLoaded` 之后、以及窗口 `resize` 时调用一次。判断只读两样东西：当前页号、当前进度。

| 当前页 | 显示什么 | 条件 |
|---|---|---|
| 1 | 第 1 步卡片 | 进度为空、且没有 `?p≥2` 深链 |
| 2 | 第 2 步卡片 | 进度为空或 `1`、且没有 `?p≥2` 深链 |
| 3 | 第 3 步提示条 | 进度为 `1` 或 `2`、且没有 `?p≥2` 深链 |
| 4 | 什么都不显示 | — |

`syncGuide()` 每次先**卸掉上一步的东西**（卡片、高亮环、提示条全部移除），再按上表决定装哪一样。所以"学生在第 1 步卡还开着的时候直接粘题去第 2 页"这种情形不会出现两张卡同屏：切页本身就是退场信号。

## 状态、存储与重看

**一个键，值是进度**：

| `localStorage['bsj-guide']` | 含义 |
|---|---|
| 缺省 | 没看过。第 1、2 步都会来 |
| `'1'` | 第 1 步处理过了（点了任一条，或直接从第 2 页开始）。第 1 步不再来，第 2、3 步还会来 |
| `'2'` | 第 2 步也过了。只剩第 3 步那条提示条 |
| `'done'` | 整轮结束（走完，或跳过）。永不再自动出现 |

- 与 `bsj-theme` / `bsj-ux` / `bsj-mentor` 同一命名家族。
- **因为值是进度，`bsj-guide` 天然跨会话保留**：第 1 步走过一次，第二天再来不会重播 —— 这正是 G3 要的。不需要第二个 `sessionStorage` 键，也不存在"同一轮里回首页又弹一次"的问题。
- **唯一写入点** `setGuideProgress(v)`：`localStorage.setItem('bsj-guide', v)` 在整份文件里只出现这一次。三个动作调它：第 1 步前进（`'1'`）、第 2 步前进（`'2'`）、跳过或第 3 步消失（`'done'`）。
- `?guide=1` 强制重放（等价于先清键，再从第 1 步开）；`?guide=0` 强制关掉。与 `?p=N` 同一套路，给评审、截图与演示用。
- **优先级**：`?guide=1` > `?p=N` > `?guide=0` > 进度。也就是说 `?p=2&guide=1` 会在第 2 页开第 2 步（给演示用），而 `?p=3` 默认一条引导都不出（评审/截图要的是干净页面）。
- **重看**：设置面板（`#setPop`）加第三组：

```
使用引导
第一次用的那些提示，可以再看一遍。   [重看一遍]
```

点 `#guideReplay` → 删 `bsj-guide` → 关面板 → `setPage(1)` → `syncGuide()` 重开第 1 步。

## 删掉「好题精练」之后

删的是**按钮**，不是"能进题库"这件事。三件事一起做：

1. **删掉** `#goodBar` 的 markup（`:1681-1685`）、`.goodbar` / `.gb-*` 全部样式（`:461-480`）、`.p1-ready .goodbar` 的入场动画引用（`:378`、`:381`）、以及 `$('#goodBar').addEventListener('click', openMap)`（`:3739-3740`）。
2. **换一行静态暗示**：第 1 页底部（原来 goodbar 的 `bottom:22px` 槽位）放一句不可点的：

   ```
   ↓ 835 道精选题在下面
   ```

   `--fs-meta`、`--ink-3`、居中、无边框、无背景、`<p>` 不是 `<button>`；箭头 2px 上下 2s 循环，reduced-motion 下静止。它是版面的暗示，不是第二个按钮 —— 这是对"取消按钮"的直接执行。

   `#p1Home` 底部现有的呼吸位（`--p1-bottom-space:104px`、`:99`、`:525`）不改，槽位复用。
3. **pilot 埋点跟着换**：`#goodBar` 不再存在，`watchIntake` 改成认引导卡片上那条题库选项（`[data-guide-path="qbank"]`）。**这是必须同步改的**，否则 `intake` 漏斗里 `qbank` 这一项永远是空的。

**没有加顶栏入口。** 考虑过在第 1 页顶栏中央（`body[data-page="1"] .tb-center` 现在是空的，`:555`）放一个「题库」链接，但那是把刚取消的按钮换个地方放回去，和用户的原话相悖。第 1 页靠三样东西够用：引导（一次）、静态暗示（一直）、页面本来就只有一屏高、往下滑就是题库。

## 题库默认「知识点」

## 第 2 页：从「三连条」到「一行讲法的人」

**现状**：`<div class="p2-teacher"><button class="mode-bar teacher-bar" id="teacherPick">…`（`:1740-1753`），和两张模式卡完全同构；点开是 `#mentorDlg` 浮层（`:1941-1952`）。

**改成**：两张模式卡下面一行紧凑的「讲法的人」选择器：

```
讲法的人    (派蒙)   (赫敏)   (诸葛亮)   (建华教授)
            默认
```

- 位置：`#modeList` 下面，`gap:16px`。语义顺序是"先选怎么讲，再选谁来讲"，所以它在模式卡之后，比现在的第三张卡更次要 —— 这正是要的。

## 我的判断（先说清，免得回头争）

- **不加顶栏题库入口**：那等于把取消掉的按钮换个地方放回去。
- **不做全屏遮罩**：这个引导要教的是"动手做一件事"，遮挡只会制造"关掉它"的动作。
- **第 3 步做得比第 2 步轻**：学生已经在做题了，任何需要他点击才能关掉的东西都是打断。
- **老师这一行不加容器背景**：它要看起来像一句注解，不像第三张卡。
- **断言并进已有用例，不新开**：实施时改了主意 —— 见「影响面」最后一段，引导的断言横跨三页，塞进已有块会读不懂，所以新开了一条并把 README 的数字一起改了。
- **状态用"进度"而不是"已看过"**：一个键四个值，比"看过标记 + 会话里记住第几步"少一个键，也自然解释了三步之间的先后关系。代价是进度可能停在 `1` 或 `2`，那正好是"他停在哪"的答案。
- **卡片压在所有浮层之下（z-index:39）**：不做"打开浮层就收起卡片"。收起—恢复的抖动比被盖住更烦人，而用户主动打开的浮层本来就该在最上面。
- **首屏那一行暗示用 `display:none` 收起，不是 `opacity:0`**：`.p1-down` 身上还挂着一个 `fill:both` 的入场动画，动画值会盖过普通声明 —— 实测引导刚打开的那半秒它还会露出来。这是渲染时才发现的，写在这里免得有人改回去。
