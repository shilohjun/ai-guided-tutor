# 全题库与报告接入

原始参考：用户提供的《高中物理高考真题题库》。当前源文件与校验值见 `qbank-import-manifest.json`。

## 已接入

- 835 道题使用固定 `qbank-1` 至 `qbank-835`（64 套卷），首页地图与第五页选题均读取同一注册题目，不再将题干重新导入为临时题。
- 已有 152 道题**沿用原 id 与原题面**：题库换版时只换分类标签，题面、选项、答案、解析一个字不动（新导出把行内上下标与分式压成了纯文本，用它覆盖旧题只会让已有内容变差）。
- 源导出共 861 道，其中 26 道的选项是图片、而导出没把图内联（选项位置只剩 `figs/*.png` 文件名），这 26 道挡在库外，清单见 `qbank-import-excluded.json`；补齐源图片后重新导入；不要用 `--include-broken` 强行启用仍缺图的题。
- 原始题干、选项、答案、解析及公式图片无损保存于服务端数据；公开题目 JSON 只保留题干、选项与分类，避免直接下载答案。
- 原始 KG 知识图谱：6 个模块、22 章、94 个叶节点。
- 原始 TH 方法图谱：9 个大类、29 个细分方法。保留每道题所有标签，包括只有方法大类而未标细分的情况。
- 逐题关联原始标签，知识卡补充基本关系、含义和适用条件；方法卡补充原理、复盘应用、适用范围和易错点。
- 默认突出前 3 个知识点、前 2 个方法，其余可展开，不丢弃关联。动能定理归入功能关系说明，不误写成动能守恒。
- 四道仅标到章节的题保留服务端 `knowledgeScope: chapter` 来源信息，报告显示「章节复习（未细分）」；节点ID与题库分类保持不变。
- 未开始聊天时也可展示题库报告资料，但明确记录不足，不生成个人掌握或正确率结论。

## 换版怎么跑

题库 HTML 更新后，一条命令重算全部产物（旧题保号、保内容，新题接在后面编号）：

```powershell
node scripts/qbank-import/build.mjs --source "高中物理高考真题题库 (4).html"
node scripts/qbank-import/check-review.mjs   # 新叶节点缺文案会在这里列出来，补齐后再放进 qbank-review.js
node scripts/qbank-import/stats.mjs          # 题量/套卷/图片张数与两棵树计数自洽性
```

脚本会顺手补源数据的漏，并在报告里逐条列出来，不静默丢标签：

- 只标到章节、没标叶子的题 → 落到本章「综合应用」叶子；
- 只标到方法大类、没标细分的题 → 保留大类，细分留空（不替源数据编分类）；
- 引用了导出方已删掉的节点（本版是 `c-实验-热学实验` / `k78 气体等温变化`）→ 按上一版名字把节点补回树上。

## 检索与地图（两个页面）

- `public/qbank/workbench.html`：**题库工作台**。左边知识点 / 思路两棵树，中间按题型、难度两行过滤 + 关键词搜索 + 分页列表，右边完整题干与选项；`↑/↓` 换题、`复制题干`、`用这道题开始`（内嵌时 postMessage 给宿主，独立页写 `sessionStorage` 后回主应用）。深链接 `?q=<题号>`、`?leaf=<叶子 id>` 可直接打开。
- `public/qbank/map.html`：地图。分类视角切换浮在导图右上角；导图与右侧题库之间有可拖动分隔条（双击复位，宽度记 `localStorage`）；列表卡片把公式**直接画出来**——行内 `$…$` 走 KaTeX，公式图内联原图，图形只留〔图〕占位，不再是 `⟨式⟩`。
- 两个页面都自带 KaTeX（`/vendor/katex/` + `/math.js`），不依赖宿主页面。

## 文件与数据流

`public/qbank/data.json` 地图选题 → `/api/problem?id=qbank-N` → `registry.js` → `qbank.js` → 服务端原始题库与图谱数据 → `/api/report` → 报告知识与方法卡。

- `src/core/qbank-source.data.js`：原始题目与答案解析资料（服务端，含图片）。
- `src/core/qbank-graphs.data.js`：源知识／方法节点及 ID。
- `src/core/qbank-review.js`：基本知识和方法说明、逐题 ID 映射。
- `src/core/qbank.js`：稳定题目注册与参考答案关联。
- `scripts/qbank-import/`：换版管线（解析、保号、补标签、写产物）与两个自检脚本。
- `test/qbank-report.test.mjs`：全题库资料完整性、对应关系、答案投影隔离、渲染折叠及 835 个真实报告接口检查。

## 验证范围与后续工作

这里保证的是 **835/835 都有原题库标签对应的知识与方法报告**，而不是声称已为每题生成并人工审核完整的解题步骤图谱。

原始公式图片被完整保留，但没有自动识别为 LaTeX／结构化量值。文本中的 `〔式〕` 等占位不能被当作已识别公式。当前题库辅导路径仍使用通用骨架；答案与解析已经留在服务端供既有核验链路使用，但没有额外改写模型提示词或调用多模态模型解析全部图片。复杂公式的语义理解、逐步判题及学生掌握诊断仍需后续公式转写和逐题教研验证。无 Key 时报告资料可用，不代表真实 AI 辅导质量已验证。

**已知内容短板**：新导出的 683 道新题里，行内上下标与分式被压成纯文本（`1.3×10-18`、`e2B2(x22+b2)28mb2`），公式图仍在、但这类行内排版没法读；另有 12 道题的题干、4 道题的选项里是不带 `$` 的裸 TeX（`{}^{14}_{6}\mathrm{C}`），渲染不了。要根治得让上游重新导出带 `<sup>/<sub>/frac>` 与统一公式定界符的版本，或另案把这些行内公式转成图片/LaTeX。

知识与方法说明是依据源标签编写的教材层面复盘，不是从完整答案逐句抽取出来的个性化解法。个人掌握算法继续保持保守，题目标签不等于学生已掌握。
