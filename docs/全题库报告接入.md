# 全题库与报告接入

本地项目：`D:\AIE3905\main`。原始参考：用户提供的《高中物理高考真题题库.html》。源文件校验值见 `qbank-import-manifest.json`。

## 已接入

- 152 道题使用固定 `qbank-1` 至 `qbank-152`，首页地图与第五页选题均读取同一注册题目，不再将题干重新导入为临时题。
- 原始题干、选项、答案、解析及公式图片无损保存于服务端数据；公开题目 JSON 只保留题干、选项与分类，避免直接下载答案。
- 原始 KG 知识图谱：6 个模块、22 章、75 个叶节点。
- 原始 TH 方法图谱：9 个大类、28 个细分方法。保留每道题所有标签，包括只有方法大类而未标细分的情况。
- 逐题关联原始标签，知识卡补充基本关系、含义和适用条件；方法卡补充原理、复盘应用、适用范围和易错点。
- 默认突出前 3 个知识点、前 2 个方法，其余可展开，不丢弃关联。动能定理归入功能关系说明，不误写成动能守恒。
- 未开始聊天时也可展示题库报告资料，但明确记录不足，不生成个人掌握或正确率结论。

## 文件与数据流

`public/qbank/data.json` 地图选题 → `/api/problem?id=qbank-N` → `registry.js` → `qbank.js` → 服务端原始题库与图谱数据 → `/api/report` → 报告知识与方法卡。

- `src/core/qbank-source.data.js`：原始题目与答案解析资料（服务端，含图片）。
- `src/core/qbank-graphs.data.js`：源知识／方法节点及 ID。
- `src/core/qbank-review.js`：基本知识和方法说明、逐题 ID 映射。
- `src/core/qbank.js`：稳定题目注册与参考答案关联。
- `test/qbank-report.test.mjs`：全题库资料完整性、对应关系、答案投影隔离、渲染折叠及 152 个真实报告接口检查。

## 验证范围与后续工作

这里保证的是 **152/152 都有原题库标签对应的知识与方法报告**，而不是声称已为每题生成并人工审核完整的解题步骤图谱。

原始公式图片被完整保留，但没有自动识别为 LaTeX／结构化量值。文本中的 `〔式〕` 等占位不能被当作已识别公式。当前题库辅导路径仍使用通用骨架；答案与解析已经留在服务端供既有核验链路使用，但没有额外改写模型提示词或调用多模态模型解析全部图片。复杂公式的语义理解、逐步判题及学生掌握诊断仍需后续公式转写和逐题教研验证。无 Key 时报告资料可用，不代表真实 AI 辅导质量已验证。

知识与方法说明是依据源标签编写的教材层面复盘，不是从完整答案逐句抽取出来的个性化解法。个人掌握算法继续保持保守，题目标签不等于学生已掌握。
